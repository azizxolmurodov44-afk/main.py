# Qon Hayoti - qon donorligi platformasi

Uzbek tilidagi responsive qon donorligi jamoadan o'rnida ishlaydigan statik
demo platforma. Sahifada qon ehtiyojlari, filterlar, jarayon va FAQ mavjud.
Real shaxsiy ma'lumot, sog'liq ma'lumotlari yoki ro'yxatdan o'tish serverga yuborilmaydi.
Ro'yxatdan o'tish va login interfeysi demo rejimda ko'rsatiladi; real hisob saqlash uchun Supabase Project URL va public anon/publishable key talab etiladi.

- Python bo‘yicha 120 ta savol
- HTML bo‘yicha 20 ta savol
- Test yakunida javoblar va tushuntirishlar
- Foydalanuvchi savol, to‘rtta variant va to‘g‘ri javobni kiritib, o‘z testini tuzishi mumkin

Sayt statik va qo‘shimcha paket talab qilmaydi. Sinab ko‘rish uchun loyiha papkasida:

```powershell
python -m http.server 8080
```

So‘ng brauzerda `http://localhost:8080` manzilini oching.
